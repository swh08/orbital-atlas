# 轨道图谱

基于 Three.js 的交互式太阳系可视化。项目使用 J2000 近似轨道参数、Kepler 方程、独立自转和轴倾，并在可观察的压缩比例下呈现太阳、八大行星、月球、小行星带、银河与分光谱星场。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 交互

- 拖动：环绕镜头
- 滚轮或双指缩放：改变观察距离
- 点击天体或使用“天体”目录：聚焦天体
- 空格：暂停或恢复原时间倍率
- `[` / `]`：降低或提高时间倍率
- `T`：开始或停止自动导览
- `Esc`：返回全景
- 自由飞行：`WASD` 移动，`Q/E` 升降，`Shift` 加速

## 渲染策略

- ACES Filmic 色调映射与线性工作流
- 仅高亮发光区域进入 Bloom 阈值
- 程序化太阳光球、日冕与磁环
- GPU 实例化小行星与星点
- 全距离固定高细分行星球体与设备原生 DPR，不使用远近几何降级
- 所有天体的最终颜色、云层、高程与环系资源均随项目本地打包，不在聚焦时依赖远程下载
- 桌面端与移动端使用同一套最终纹理、几何、抗锯齿与后期管线，不设自动低画质或隐藏的画质保存项
- 统一的太阳定向照明、材质响应、大气昼夜侧衰减与近景取景标准
- WebGL 上下文丢失提示与页面隐藏自动暂停
- `prefers-reduced-motion` 与 `prefers-reduced-transparency` 降级

## 科学边界

轨道偏心率、倾角、周期、自转和轴倾来自 JPL/NASA 近似参数，轨道位置通过 Kepler 方程求解。为了让太阳与行星能在同一屏幕中观察，天体半径和轨道距离使用不同的显示压缩函数，因此画面不是统一真实比例。

NASA、USGS 与 NOAA 档案通常提供颜色、反照率、地形或任务/模型合成图，并不提供所有天体统一的 roughness、AO、metalness 和 normal PBR 套图。本项目将观测颜色、模型纹理与渲染派生材质明确区分。气态与冰巨行星也不会被描述为拥有实测固体高度图。

金星的 Magellan 资源是雷达衍生的表面基线，并非肉眼可见的地表颜色；实际近景由不透明的程序化浓云层遮住表面。土星颜色图来自 NOAA Science On a Sphere 目录（Bjorn Jonsson、Steve Albers），不归作 NASA 资产；土星环纹理则单独提取自 NASA VTAD 的 Saturn GLB。

天王星与海王星使用 NASA VTAD GLB 内提供的 1024 × 512 模型纹理，这是源文件本身的分辨率上限。渲染器以统一材质和光照补充细微的大气层次，但不会把这些细节描述成更高分辨率的观测数据，也不会通过简单放大伪装成 4K 来源。

完整的资源、署名与许可记录见 [public/SOURCES.json](./public/SOURCES.json)。

## 画质说明

最终天体资源已离线转换并本地打包：金星、地球与火星主图为 4096 × 2048，地球云层、夜光和高程及火星高程同为 4096 × 2048；木星为 3601 × 1801；土星为 2880 × 1440，环系径向纹理为 4096 × 16；天王星与海王星保留源 GLB 的 1024 × 512。运行时不会为了移动端或首屏加载而替换为低分辨率天体贴图。

浏览器不直接传输各档案的 8K/16K 原始母版，而是使用上述经过本地预处理的最终资源。若后续获得更高分辨率且出处明确的冰巨星资产，应通过 KTX2、纹理流送与缓存扩展替换当前本地文件，并同步更新来源记录。
